## MCP 2 つが同じ形になった

houki-egov-mcp v0.5.3 と houki-nta-mcp v0.10.0 以降は、次の点が同一になった。

- `@modelcontextprotocol/server` v2 の低レベル `Server` を使い、`src/server.ts` の `createServer()` と `src/index.ts` の `serveStdio` に分ける
- tools/call の引数は `inputSchema`（JSON Schema）から自前で検証し、違反は `INVALID_ARGUMENT` で返す
- エラー応答は family contract（`UNKNOWN_TOOL` / `INVALID_ARGUMENT` / `INTERNAL_ERROR` + `isError: true`）。houki-nta-mcp v0.9.5 までは `{ error }` だけで `isError` が付いていなかった
- `engines.node >= 22`、CI は Node 22 / 24、lint / format は Biome、TypeScript 7

これにより、claude-plugins の README にあった「nta は SDK v1 の例外」という注記を外せた。

## houki-egov-mcp で見つかった罠（v0.5.1 で修正）

XML パーサーが `MainProvision > Part`（編）を辿っておらず、民法・会社法のように編を持つ法令の本則が bulk DB に入っていなかった。
fixture が `Chapter` 直下だったため単体テストでは見えず、実データで「民法 不法行為」を引いて初めて分かった。
再取り込みは `content_hash` に `INGEST_VERSION` を混ぜることで強制する。パーサーを触ったら `INGEST_VERSION` を上げる。
