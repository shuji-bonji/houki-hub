# issue 草案: 削除された条を個別の条番号で引けない

対象リポジトリ: houki-egov-mcp（2026-09-20 JST 作成）
提出先: https://github.com/shuji-bonji/houki-egov-mcp/issues
タイトル案: 削除された条を個別の条番号で引けるようにする（`Num="534:535"` に `article: "534"` を当てる）

---

## 観察

v0.14.0 の `get_law_range` で民法第三編第二章を読み進めたときに、削除された条が現れました。

```
## 第534:535条

削除
```

e-Gov の法令データは、削除された条を**複数まとめて 1 つの `Article` で持っています**。

```jsonc
{ "tag": "Article", "attr": { "Num": "534:535" }, "children": [
  { "tag": "ArticleTitle", "children": ["第五百三十四条及び第五百三十五条"] },
  { "tag": "Paragraph", "attr": { "Num": "1" }, "children": [ /* 「削除」 */ ] }
]}
```

表示（`第534:535条`）と `get_law_range` の続き（`from_article` が `"534:535"` を受けなかった）は v0.14.1 で直しました。この Issue は残っている 1 点です。

## 残っている問題

`get_law` に個別の条番号を渡しても引けません。`findArticle()` が `attr.Num` の完全一致で探すため、`"534"` は `"534:535"` に当たりません。

```jsonc
// get_law { "law_name": "民法", "article": "534" }
{ "code": "ARTICLE_NOT_FOUND", "error": "条文が見つかりません: 第534条 in 民法" }
```

利用者や LLM は「民法第534条」と書きます。`"534:535"` という書き方を知っているのは、`get_toc` か `get_law_range` の応答を見た後だけです。同じことが `verify_citations`（`ARTICLE_NOT_FOUND` になる）と `get_article_references` にも起きます。削除条の引用を「存在しない条」と判定してしまうため、`verify_citations` では特に困ります。

## 実測（2026-09-20）

主要 8 法令に 28 件ありました。全件で本文は「削除」です。

| 法令 | 件数 | 例 |
|---|---|---|
| 商法 | 9 | `32:500`（第三十二条から第五百条まで）・`813:814` |
| 民法 | 8 | `534:535`・`170:174`・`38:84` |
| 刑法 | 3 | `73:76`・`90:91` |
| 法人税法 | 3 | `92:120`・`136:137` |
| 所得税法 | 2 | `96:101`・`234:236` |
| 労働基準法 | 2 | `29:31`・`43:55` |
| 会社法 | 1 | `930:932` |
| 消費税法 | 0 | — |

範囲の広いものがあります（商法 `32:500` は 469 条分、民法 `38:84` は 47 条分）。「第百条は削除されているか」を条番号だけで答えるには、範囲に含まれるかを数で判定する必要があります。

## 実施項目（案）

- `findArticle()` に、範囲表記の `Num` を数の範囲として照合する経路を足す（`534` は `534:535` に含まれる、`100` は `38:84` に含まれない）
- 完全一致を優先し、範囲表記への照合は当たらなかったときだけにする（枝番号の条 `Num="30_2"` と混ざらないようにする）
- 照合で当たったときは、応答に「指定した条は削除されています」と、まとめられている範囲（`第五百三十四条及び第五百三十五条`）を示す。`get_law` の Markdown の見出しは範囲の表示（`第534条及び第535条`）にする
- `verify_citations` は、削除条の引用を `not_found` にせず `found` として返すか、削除された旨を付けた別の判定にするかを決める（**要検討**: 「実在するが削除済み」は `found` と `not_found` のどちらでもない）
- `get_article_references` の参照解決でも同じ照合を使う

## 完了条件（案）

- `get_law { "law_name": "民法", "article": "534" }` が「第534条及び第535条 削除」を返す
- `get_law { "law_name": "民法", "article": "100" }` は従来どおり第100条（削除されていない条）を返す
- `verify_citations` で削除条の引用の扱いが決まっていて、応答からその条が削除済みだと分かる

## 決まっていないこと

- `verify_citations` の判定（`found` に含めるか、`deleted` のような値を足すか）
- 「削除されている」ことを応答のどのフィールドで示すか（`article.deleted: true` を足すか、`note` に書くか）
