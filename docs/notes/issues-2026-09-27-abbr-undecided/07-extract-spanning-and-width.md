`extractLawNames` は、2 つの法令名にまたがる短い一致を返します。また、全角・半角の表記ゆれを吸収しません。文章から法令名を拾う用途（LLM の回答の検証など）で、文中に書かれていない略称を拾ったり、書かれている法令名を拾えなかったりします。

### いまの状態

| 入力 | 結果 | 問題 |
|---|---|---|
| `消費税法法人税法` | `消費税法`（位置 0）、`法法`（位置 3）、`法人税法`（位置 4） | `法法` は文中に書かれた略称ではない（`消費税法` の `法` と `法人税法` の `法`） |
| `ＰＬ法`（全角の `ＰＬ`） | `[]` | `PL法` なら `製造物責任法` の一致を返す。`searchByName` と `findSimilar` は既定で全角を吸収する |

今は、一致の範囲がほかの一致の範囲に完全に含まれるときだけ除きます。

### 決めること

- ほかの一致にまたがる一致を除くか
- 探す前に `normalizeJpText` を通すか（通すなら、返す `position` と `length` を元の文字列の位置で返すか）

### 完了条件

- 上の 2 つの入力の結果が仕様に書かれ、受入テストがある
