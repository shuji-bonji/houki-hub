## 追記: #47 から移した 3 つ（2026-10-03 JST）

#47（時点の引数 `at` の形）は v0.16.0 で形の検査を入れて閉じました。#47 の「決めること」のうち、形の検査では片付かない次の 3 つをこの Issue に移します。どれも「law_id と `at` が決まった後に、e-Gov が 400・404 を返す」場面で、この Issue の「決めること」1・3 と一緒に決める必要があります。

1. **形は正しいが、その時点に法令がまだ無い `at`。** e-Gov は 400 か 404 を返します。v0.17.0 では、`get_law` などは `SOURCE_API_ERROR`（`retryable: false`）、`verify_citations` はその件を `LAW_NOT_FOUND` にします。`LAW_NOT_FOUND` にするなら、`hint` で「`at` の時点にこの法令が無い」ことを言い分けるか（この Issue の「決めること」2）
2. **`verify_citations` で `at` を法令名の検索にも使うか。** 今は法令名の検索と略称辞書の引き当てに `at` を使わず、本文の取得にだけ `asof` を付けます。ある時点にだけあった法令の名前で引くと、法令名の検索で別の法令に当たるか 0 件になる可能性があります
3. **`verify_citations` の未決 2「e-Gov の 400 を『law_id が無い』と書くことがある」。** `isLawIdRejected()` は 400 も 404 も「e-Gov に law_id … の法令がありません」にします。原因が `at` でも同じ文になります。`specs/current/verify_citations/spec.md` の未決 2 の指す先を、#47 からこの Issue に直します
